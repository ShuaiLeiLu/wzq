# 弈间 · 五子棋 · 斗地主

在线棋牌游戏大厅：双人实时五子棋，和三人斗地主。

- `/` 是游戏大厅：两款游戏的入口、实时人数、快捷开局，以及两份今日排行。大厅的房号输入框对两种游戏都有效。
- `/wzq` 是五子棋大厅，`/ddz` 是斗地主大厅。两种游戏共用一套四位房间号，打开 `?room=房号` 的链接会自动进入对应游戏的房间，旧的 `/?room=房号` 邀请链接继续可用。
- 坐在一个房间里时也可以切到另一款游戏的大厅随便看看，页面顶部会提示「回到房间」。一个人同一时间只能坐在一个房间里。

## 运行

安装 Rust 稳定版和 Cargo。在项目目录运行以下命令，启动后打开 [http://localhost:3000](http://localhost:3000)。首次构建会下载 Rust 依赖。

```sh
cargo run --locked
```

端口默认是 `3000`，可通过环境变量 `PORT` 修改。服务默认监听 `0.0.0.0`，也可以用 `HOST` 指定监听地址。Rust 服务内嵌前端静态资源，发布时只需要后端可执行文件。

## 五子棋

点击右上角「登录」可用智算账号的邮箱和密码登录；启用二次验证的账号还需输入动态验证码。没有账号可以从登录窗口前往智算注册和验证邮箱，也可以直接以访客身份对弈。弈间使用智算账号的用户 ID 识别账号，并显示用户名和可用的头像。账号会话有效期为 12 小时，退出登录后会恢复访客身份。

1. 使用两个浏览器窗口或两个设备打开同一个服务地址。右上角可以登录或编辑访客昵称。
2. 两人分别从大厅进入同一间房。也可以一人创建房间，再把邀请链接或四位房间号发给另一人。
3. 双方点击「准备」。首局随机分配黑白，黑棋先行。原班两人在同一棋室再开局时交换黑白，换棋手后重新抽签。每手限时 30 秒，超时判负。横、竖、斜任一方向连成五子或更多即可获胜。

开局前，任一位棋手都可以在自己的座位卡片上选择「我让对方」：让先、让二子或让三子。让方执白，被让方执黑。让先时由黑棋先行；让二子和让三子会先在 H8、I9（三子再加 G9）摆好黑子，然后由白棋先走。修改让子会取消双方准备，双方重新准备即视为同意。有棋手离座或换人时恢复不让。让子局不计入排行榜。

对局中，自己刚落子、对方还没落子时，可以申请悔棋，撤回自己的上一手。对方同意后撤回这一手，由申请人重新落子，并重新计时 30 秒。对方拒绝或 10 秒内未回应，对局照常继续。等待回应期间双方计时暂停，有棋手掉线则申请自动取消并返还次数。每人每局最多申请 3 次，被拒绝也计入次数；同一手被拒绝后不能再次申请。让子设置和悔棋都会在棋室对话中留下系统消息。悔棋局照常计入排行榜。

大厅的「排行榜」按北京时间每天 00:00 重置。开局时已登录的棋手，胜一局加 1 分、负一局扣 1 分、和棋积分不变。游客可查看榜单。榜单显示前 20 名，登录棋手还可以查看自己的当日名次。上一日的榜首会在大厅和棋室顶部全站播报。

观众可以点大厅房间旁的「观战」，也可以打开棋手分享的观战链接。棋盘、倒计时和胜负会实时更新。棋手和观众都能在「棋室对话」中发消息，同房成员会在对话记录中看到新消息。弹幕默认开启，新消息会从棋盘右侧飘入，从左侧飘出。可以从棋盘工具栏开关弹幕。每个棋室保留最近 40 条消息，棋室清空或服务重启后移除。

## 斗地主

一副 54 张牌，三人一桌，每人 17 张，留 3 张底牌。牌从小到大是 3 到 K、A、2、小王、大王。

1. 在斗地主大厅点「快速开局」坐进有人在等的牌桌，或「创建牌桌」后把邀请链接发给牌友。人不够时，坐着的玩家可以点「补机器人」；真人入座会替换机器人。「人机练习」直接开一桌两个机器人的私人牌桌。
2. 三个座位坐满、真人都点「准备」后发牌。系统随机选一人先叫地主。有人叫地主后，之后没说「不叫」的人可以抢地主，最先叫的人最后还能再抢一次，每抢一次倍数 ×2。三家都不叫就重新发牌。地主拿走底牌，底牌对所有人可见。
3. 定下地主后每人选择是否加倍（×2）。地主在出第一手前可以明牌（×2），明牌后所有人都能看到地主的手牌。
4. 地主先出。支持单张、对子、三张、三带一、三带一对、顺子（5 张起，3 到 A）、连对（3 对起）、飞机（可带同数量的单张或对子，王炸不能拆开当翅膀）、四带二（两单或两对，不算炸弹）、炸弹和王炸。跟牌须同牌型、同张数且更大；炸弹压一切非炸弹，王炸最大。每打出一个炸弹或王炸，倍数 ×2。有歧义的牌（例如 33334444）跟牌时按上家的牌型解读。
5. 先出完手牌的一方获胜。地主出完而农民一张未出为春天，农民获胜而地主只出过一手为反春，各 ×2。每位农民的输赢 = 公共倍数 × 地主是否加倍 × 本人是否加倍，单人封顶 64 分，地主输赢为两位农民之和。

叫地主和加倍限时 15 秒，出牌限时 25 秒。叫地主或出牌超时会自动托管，加倍超时视为不加倍。断线的玩家 3 秒后由托管代打，回来后点「取消托管」即可接手。牌局中离开牌桌，座位由托管代打到本局结束，输赢照常结算。机器人和托管使用同一套出牌策略：尽量少拆牌型、不压队友，对手快出完时才动用炸弹。

出牌时可以点选或在手牌上拖动选牌，右键清空选择，「提示」会依次给出能压过上家的出法，回车出牌。牌桌上有记牌器，显示还没出现的牌，可以从工具栏关闭。牌桌对话、弹幕和观战与五子棋相同，另有一组快捷语和表情。

三位真人入座、至少一人登录智算账号的牌局计入斗地主今日积分榜，按积分排名，北京时间 00:00 重置。有机器人的牌局和人机练习不计排行。上一日的斗地主榜首会在斗地主大厅顶部播报。

## 部署与数据

同一局域网内，其他设备使用运行服务的电脑的局域网地址，例如 `http://192.168.1.10:3000`。跨网络对弈需要把项目部署到双方都能访问的主机，反向代理应支持实时事件流（SSE），并关闭该路径的响应缓冲。

棋室、牌桌、昵称和对局保存在服务进程的内存中，重启服务会清空。五子棋棋手断线后会暂停倒计时并保留座位 45 秒，重连后继续计时；掉线超时会释放座位，进行中的对局判对方获胜。斗地主玩家掉线 45 秒后视为离开牌桌，本局由托管打完。

Rust 后端通过 HTTPS 调用 Sub2API 的 `/api/v1/auth/login`、`/api/v1/auth/login/2fa` 和 `/api/v1/auth/me`。默认地址为 `https://zhisuanapi.cn`，测试时可通过环境变量 `SUB2API_ORIGIN` 指向本地模拟服务。

排行榜通过 PostgREST 写入 PostgreSQL，数据库卷独立于游戏发布。PostgREST 默认只监听 `127.0.0.1:3042`。自建时，在 `ops/leaderboard` 的 Compose 环境中设置 `WZQ_DB_OWNER_PASSWORD`、`WZQ_DB_AUTH_PASSWORD`（使用只含十六进制字符的随机密码）和 `WZQ_POSTGREST_JWT_SECRET`，然后运行 `docker compose up -d`。Rust 服务使用 `WZQ_POSTGREST_TOKEN` 连接，令牌由同一个 JWT 密钥以 HS256 签名，并带有 `role: wzq_app` 声明。可用 `WZQ_POSTGREST_ORIGIN` 指向其他 PostgREST 地址。

已有排行榜数据库可从 `ops/leaderboard` 目录执行 `docker compose exec -T db psql -U wzq_owner -d wzq -v ON_ERROR_STOP=1 < champion.sql` 安装昨日榜首查询，执行 `docker compose exec -T db psql -U wzq_owner -d wzq -v ON_ERROR_STOP=1 < ddz.sql` 安装斗地主积分榜。两个脚本都可以重复执行。新数据库由 Compose 初始化，迁移会通知 PostgREST 重载接口。斗地主积分榜未安装时，游戏照常进行，只是不显示和不记录斗地主积分。

## 自动发布

线上棋室使用 [https://wzq.zhisuanapi.cn](https://wzq.zhisuanapi.cn)。

向 `main` 推送后，GitHub Actions 会检查前端语法和 Rust 代码，构建 Docker 镜像 `wzq-server:<提交号>`，并通过独立部署密钥把镜像上传到服务器。也可以从 GitHub 仓库的 Actions 页面手动运行 `Deploy Gomoku`。服务器只接受标签正好是本次提交号的镜像，加载后用它替换 `wzq` 容器并检查 `/healthz`，检查失败时会恢复上一版本的镜像。服务器保留最近 3 个版本的镜像。每次发布都会重启容器，清空正在进行的对局和登录会话。

游戏容器使用主机网络，只监听 `127.0.0.1:3041`，从 `/etc/wzq/leaderboard.env` 读取排行榜配置。该文件需要部署用户可读，且值不能加引号。容器以非 root 用户运行，文件系统只读，内存上限 192 MB，日志自动轮转。服务器上的部署用户 `wzq-deploy` 需要在 `docker` 组中，它的 SSH 密钥只能执行 `ops/deploy.sh`。HTTPS 由现有 Caddy 按 `ops/wzq.caddy` 反代。自动发布需要仓库密钥 `WZQ_DEPLOY_SSH_KEY`，以及变量 `WZQ_DEPLOY_HOST` 和 `WZQ_DEPLOY_KNOWN_HOST`。

查看线上服务可在服务器上运行 `docker ps --filter name=wzq` 和 `docker logs -f wzq`。
